Quick Commands
# Nuke ALL DerivedData rm -rf ~/Library/Developer/Xcode/DerivedData/*
# Nuke preview caches only find ~/Library/Developer/Xcode/DerivedData \ -path "*/Build/Intermediates.noindex/Previews" \ -type d -exec rm -rf {} + 2>/dev/null
# Nuke caches older than 7 days find ~/Library/Developer/Xcode/DerivedData \ -maxdepth 1 -mindepth 1 -type d \ -mtime +7 -exec rm -rf {} +
What Gets Nuked

Build Products

Compiled binaries, object files, and linked frameworks. Xcode rebuilds these on next compile.

Preview Caches

SwiftUI preview artifacts that accumulate and go stale, causing the dreaded "Preview Failed" errors.

Index Data

Source code indexes for autocomplete and navigation. Rebuilt automatically on next project open.

Module Caches

Precompiled module maps and Swift module interfaces. Safe to delete — Xcode regenerates them.

Automation

Auto-Clean Shell Script

Download a shell script that monitors DerivedData and auto-cleans stale caches. Run via launchd or cron for hands-free maintenance.
